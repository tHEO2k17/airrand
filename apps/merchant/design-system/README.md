# Merchant design system

CSS tokens and POS styles for the merchant app. See [docs/design-system.md](../../../docs/design-system.md) for the full brand and notification UI guidelines.

- `tokens.css` — colors, spacing, typography, layout variables
- `pos.css` — POS shell, cards, alerts, order line, sidebar

Notification feedback uses `AlertMessage` and `NotificationFeedback` in `components/ui/`.
